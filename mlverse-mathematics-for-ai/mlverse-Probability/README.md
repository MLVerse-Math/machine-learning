# 🎲 Phase 3: Probability

> **Goal:** Model uncertainty mathematically.

Probability is the mathematical language of uncertainty. Every Machine Learning model, Artificial Intelligence system, and statistical algorithm operates under uncertainty, making probability one of the most essential foundations for modern AI.

This phase introduces the core principles of probability, beginning with sample spaces and events, progressing through conditional probability and Bayesian reasoning, and culminating in probabilistic models such as Markov Models. By the end of this phase, you'll understand how intelligent systems reason under uncertainty, make predictions from incomplete information, and model real-world randomness.

---

# 🎯 Learning Objectives

After completing this phase, you will be able to:

- Understand uncertainty using probability theory.
- Model events and outcomes mathematically.
- Compute conditional probabilities.
- Apply Bayes' Theorem to update beliefs using evidence.
- Work with discrete and continuous random variables.
- Analyze joint and marginal probability distributions.
- Understand statistical independence.
- Use common probability distributions in AI and Machine Learning.
- Build intuition for stochastic systems and Markov Models.
- Apply probabilistic reasoning to real-world AI problems.
