# Partial Derivatives

## Overview

Most Machine Learning models depend on multiple variables rather than a single variable.

For example:

$$
L(w,b)
$$

where:

- $w$ = weight
- $b$ = bias

To optimize such functions, we need Partial Derivatives.

Partial derivatives measure how a multivariable function changes when one variable changes while all other variables remain constant.

They form the foundation of:

- Gradient Descent
- Neural Networks
- Backpropagation
- Computer Vision
- Reinforcement Learning
- Deep Learning
