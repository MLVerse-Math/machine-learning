# Functions

## Overview

Functions are the fundamental building blocks of Calculus, Machine Learning, and Artificial Intelligence.

A function defines a relationship between inputs and outputs.

Almost every concept in AI can be represented as a function:

- Activation Functions
- Loss Functions
- Optimization Functions
- Probability Functions
- Neural Network Layers

Understanding functions is the first step toward mastering Calculus and Machine Learning.
