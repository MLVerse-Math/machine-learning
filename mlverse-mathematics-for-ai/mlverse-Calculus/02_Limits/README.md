# Limits

## Overview

Limits are the foundation of Calculus.

They describe how a function behaves as the input approaches a particular value.

Limits are essential because they lead to:

- Continuity
- Derivatives
- Integrals
- Optimization
- Gradient Descent
- Deep Learning Mathematics

Without limits, modern Calculus would not exist.
